# Rock Paper Scissors

A simple console game written in Java. Play against the computer, track the score, and keep playing as long as you like.

## Features
- Play against a random computer opponent
- Score tracking (wins, losses, ties)
- Input validation (invalid input just asks again)
- Short inputs supported: `r`, `p`, `s`

## Technologies
- Java
- IntelliJ IDEA

## How to run

**In IntelliJ IDEA:** open the project and run `Main.java`.

**From the terminal:**
```bash
cd src
javac *.java
java Main
```

## Project structure
```
src/
 ├── Main.java   # entry point
 ├── Game.java   # game logic and user interaction
 └── Move.java   # ROCK / PAPER / SCISSORS and the win rules
```
